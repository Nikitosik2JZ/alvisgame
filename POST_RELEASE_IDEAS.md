# Deferred ideas — possible 1.1

These ideas are outside the 1.0 release candidate and are not implemented.

- Measure real draft-player progression and retention before further economy adjustments.
- Expand original SFX only after physical-device sound and accessibility feedback.
- Add optional tutorial replay from Settings while retaining the once-only automatic tutorial rule.
- Add more contextual events after reviewing actual interruption rates and anti-frustration data.
- Consider richer celebrations with an explicit effects setting and measured mobile cost.
- Explore new districts, vehicles or company depth only as a separately approved content update.
- Improve browser/device test automation and collect long-session memory profiles.
- Consider server-authoritative ranking validation if real abuse justifies the additional infrastructure.

No new prestige system, multiplayer, purchases, battle pass, city, apartments or warehouse mechanics are included in Stage 12.
